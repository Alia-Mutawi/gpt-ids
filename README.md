# IoT IDS Dashboard — Botnet & Slowloris

واجهة ويب تعليمية لعرض تنبؤات النموذج الخفيف المحفوظ من مشروع Kaggle. تعتمد على خصائص تدفق شبكة محسوبة مسبقاً، وليس على التقاط الحزم مباشرة.

## محتويات الحزمة

- `app.py`: واجهة Streamlit باللغة العربية، لتحليل CSV أو تدفق واحد.
- `xgb_lightweight_final.json`: النموذج بصيغة XGBoost الأصلية.
- `preprocessing.json`: أسماء الخصائص، وقيم التعويض، ومتوسطات/مقاييس التوحيد، وترتيب الفئات.
- `requirements.txt`: متطلبات التشغيل.

## تشغيل محلي

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## النشر المجاني على Streamlit Community Cloud

1. فكّي ضغط الحزمة.
2. أنشئي مستودعًا في GitHub وضعي الملفات الأربعة أعلاه في جذر المستودع. لا ترفعي بيانات شبكة حساسة أو ملفات PCAP أو بيانات أشخاص.
3. افتحي https://share.streamlit.io وسجلي الدخول بواسطة GitHub.
4. اختاري **Create app / Deploy an app**، ثم المستودع والفرع وملف `app.py`.
5. انشري التطبيق. عند حدوث خطأ في البناء، افتحي سجلات التطبيق وتحققي من تثبيت الحزم في `requirements.txt`.

خدمة Community Cloud مجانية، لكن الموارد وسياسات الاستخدام قد تتغير، كما أن التطبيقات غير النشطة قد تتوقف مؤقتًا. راجعي الوثائق الرسمية قبل التسليم النهائي.

## تنسيق ملف CSV

يجب أن يحتوي الملف على الأعمدة التالية؛ تتم مطابقة الأسماء بعد تحويل الحروف إلى lowercase وتحويل المسافات إلى `_`:

```text
flow_duration,flow_iat_mean,flow_iat_min,fwd_iat_max,bwd_iat_max,bwd_iat_min,flow_iat_max,bwd_iat_std,fwd_iat_min,down/up_ratio
```

يمكن أن يحتوي الملف أعمدة إضافية مثل `Label` أو `Source IP`، لكن النموذج لا يستخدمها. تُستبعد الصفوف التي تكون خصائصها العشر كلها مفقودة أو غير رقمية. حد التحليل الافتراضي 10,000 صف لتقليل استهلاك الذاكرة.

## مهم جدًا حول الأداء

بحسب نتائج التجربة المرفقة: النموذج الخفيف سجّل Accuracy يقارب 67.8% وMacro-F1 يقارب 0.270 وBalanced Accuracy يقارب 0.466. كما أن مجموعة الاختبار الحالية لا تضم عينات Slowloris؛ لذا لا يصح استخدام الواجهة كدليل على كشف فعّال أو كوسيلة حماية إنتاجية قبل إصلاح التصميم التجريبي وإعادة التقييم.

## حدود واقعية

هذه الواجهة لا تراقب الشبكة الفعلية. للانتقال إلى IDS حي، يجب تشغيل مجمّع تدفقات على جهاز داخل الشبكة (مثل بوابة IoT)، واستخراج الخصائص العشر نفسها وبالوحدات وترتيب الحساب المطابقين للتدريب، ثم إرسال النتائج إلى خدمة محمية. لا تفتحي واجهة عامة لتستقبل بيانات شبكة حساسة.
